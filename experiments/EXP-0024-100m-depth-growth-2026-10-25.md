# EXP-0024: SLM-Tavenel 100M-class depth growth

**Status: both matched training runs completed at step 1,500; 100M final benchmark evaluation remains pending.** These are local exploratory runs. The source corpus remains subject to the
rights and privacy review gaps recorded in the FSC provenance. This experiment does not clear the
data for public release.

## Question

Does doubling depth from a trained 50M-class SLM-Tavenel checkpoint improve validation loss,
bits-per-byte (BPB), or benchmark accuracy when both the expanded model and a 50M control receive
the same additional FSC token exposure?

## Design

| Arm | Initialization | Parameters | Additional training |
| --- | --- | ---: | --- |
| 50M control | EXP-0023 step 1,500 | 49,349,888 | 1,500 steps, 49,152,000 token positions |
| 100M treatment | Function-preserving 40→80 layer expansion of the same checkpoint | 96,602,368 | 1,500 steps, 49,152,000 token positions |

Both arms use seed 20261025, the same FSC pilot token shards, 1,024 sequence length, 32,768 tokens
per optimizer step, AdamW, BF16, and the same WSD schedule (3e-4 peak learning rate, 3e-5 minimum,
50 warmup steps, 20% decay). The matched 50M control makes the architecture comparison more
informative than comparing unrelated training runs. It is a token-matched comparison, not a
compute-matched one: the 100M arm requires more FLOPs. One seed per arm also means results remain
exploratory.

The 100M initialization has been checked on a fixed token probe. Maximum absolute logit difference
from the source 50M checkpoint is exactly 0 before further training.

## External reference

SmolLM2-135M is scored with the repository's pinned multiple-choice files and evaluator; the
reference checkpoint revision is `93efa2f097d58c2a74874c7e644dbc9b0cee75a2`. It is a descriptive
peer reference, not a controlled training comparison: its corpus, tokenizer, training-token budget,
and training recipe differ. The 100M model is also smaller than the 134.5M-parameter reference.

## Results

Final training losses were **2.21179** for the 50M control and **2.21203** for the 100M treatment
after 49,152,000 additional token positions each. The 100M training loss is 0.00024 higher at the
last step; this small difference alone does not establish a performance regression. The 50M
evaluation artifact is present. The 100M benchmark evaluation is still pending. The final report
will include held-out English/French FSC validation loss and BPB,
the six pinned multiple-choice benchmark scores, paired uncertainty intervals for the 50M versus
100M items/documents, and the existing SmolLM2 same-evaluator scores. No score will be interpreted
as a causal claim about performance versus SmolLM2.
