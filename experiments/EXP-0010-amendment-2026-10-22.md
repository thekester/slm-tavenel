# EXP-0010 protocol amendment — 2026-10-22

**Issued after the first paired training run started and before the sealed test was scored.**

This amendment adds two disclosures to the protocol: the optimizer schedule, token budget and
architecture were inherited from the exploratory v4 pilot, whose development results had already
been inspected; and the public source documents are held out from this project's runs but are not
secret from outside readers or from possible external pretraining corpora.

This does not change the selected corpus, split, model arms, seeds, initialization pairing, token
budget, primary outcome, bootstrap procedure, effect threshold, decision rule, or preselected
release seed. The addition narrows interpretation and does not use results from the ongoing runs.
