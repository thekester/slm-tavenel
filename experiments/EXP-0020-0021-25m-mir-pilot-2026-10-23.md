# EXP-0020/0021: 25M masked-input regularization pilot

**Status (2026-10-23 23:39 Paris):** training, matched BPB evaluation and paired-document bootstrap are complete. This is an exploratory one-seed pilot; it does not establish a universal result about MIR. Candidate checkpoints stay local because FSC rights/privacy review remains unresolved.

## Motivation

Xu et al. (2026) report that masked-input regularization (MIR), an auxiliary next-token prediction loss on randomly masked inputs, improves validation loss over a strongly regularized autoregressive baseline in data-constrained training. Their experiments cover 72M–1.4B parameters and use five seeds for headline comparisons. SLM-Tavenel's 25M model is below their smallest scale, so transfer is uncertain. This pilot asks only whether the signal is promising enough to justify replication at this scale.

## Matched design

| Run | Recipe | Seed | Steps | Processed positions | Objective |
|---|---|---:|---:|---:|---|
| EXP-0020 | FSC-only control | 20261024 | 1,500 | 49.152M | Standard next-token prediction |
| EXP-0021 | FSC-only + MIR | 20261024 | 1,500 | 49.152M | Clean loss + 0.4 × masked-input loss |

Both cells start from the same grown 25M checkpoint and use the same FSC-only token stream, tokenizer, model, AdamW settings, WSD schedule, batch size, precision, and seed. MIR samples one masking ratio per sequence uniformly from 0 to 0.5, then independently masks input positions. It uses existing reserved tokenizer ID 10 as the mask symbol, so model vocabulary size is unchanged. Targets remain the original next tokens. The auxiliary weight 0.4 and mask-ratio range follow the paper's reported setting; they are not tuned on this checkpoint.

Primary comparison: paired held-out BPB on FSC EN/FR validation. Wiki EN/FR holdouts are secondary domain-transfer diagnostics. Training losses, held-out BPB and compute cost will be reported separately. No multiple-choice test set is used to select the result. Training-seed uncertainty is not estimated by this one-seed pair; any promising finding requires an independent seed before being treated as evidence.

## Results

EXP-0020 completed in about 35 minutes with final train loss 2.21217 and periodic validation loss 2.17697. EXP-0021 took about 65 minutes; its final clean-input NTP loss was 2.22181, masked auxiliary loss 3.22435, and validation loss 2.18439. The MIR validation loss was 0.00742 higher. Its additional forward pass increased training wall time by about 1.84x in this run.

MIR had higher (worse) BPB on all four text sets. Under this 25M architecture, data, seed and token budget, the pilot gives no support for adopting MIR; document-bootstrap intervals exclude zero but do not estimate seed variability. The paper studies models from 72M upward and uses a different data/compute regime, so this one 25M result does not refute its claims at those scales. The full paired analysis is here (local artifact: `runs/EXP-0020-0021-25m-mir-2026-10-23/analysis.json`); the control evaluation (local artifact: `runs/EXP-0020-25m-fsc-control-s2-2026-10-23/evaluation-primary-text.json`) and MIR evaluation (local artifact: `runs/EXP-0021-25m-fsc-mir-s2-2026-10-23/evaluation-primary-text.json`) preserve per-document scores.

## Limits and source

The paper's smallest model is 72M, its data and compute setup differ, and MIR adds a second forward pass per batch. This pilot keeps processed-token exposure equal, not training FLOPs or wall time. A lower BPB would therefore indicate a data-efficiency signal under this protocol, not a compute-efficiency gain. FSC source rights/privacy remain unresolved; this work is local only.
