# EXP-0033: Muon optimizer transfer at 25M

**Status:** completed 2026-10-27. The matched Muon run finished all 1,500 steps and all planned development evaluations. Local exploratory experiment only.

## Question

Does the project's Muon-plus-AdamW optimizer improve held-out next-token prediction at 25M relative to AdamW when both continue from the same grown checkpoint for the same token budget?

## Frozen comparison

| Arm | Initialization | Data | Optimizer | Steps | Token positions | Seed |
|---|---|---|---|---:|---:|---:|
| Control | EXP-0009 grown 25M, step 15,000 | FSC scaling | AdamW | 1,500 | 49,152,000 | 20261028 |
| Treatment | same checkpoint | same FSC scaling shards | Muon + AdamW | 1,500 | 49,152,000 | 20261028 |

All settings other than optimizer are matched to the EXP-0032 fresh-seed FSC control. Optimizer state is reset at the continuation boundary in both arms. The primary outcome is fixed-document FSC BPB; repeated multiple-choice scores are secondary and exploratory. Compare with the EXP-0032 control checkpoint and evaluate only on the previously used development sets. Do not use the EXP-0032 HPLT test split to tune this run.

## Interpretation limits

This is one seed and one optimizer configuration, not a population-level conclusion. The earlier 25M Muon attempt (EXP-0015) stopped at step 300 with a CUDA illegal-memory-access error before its first checkpoint; it produced no valid comparison. The motivation is the positive 10M BPB result in EXP-0005, which does not guarantee transfer to 25M. Existing FSC data-rights and privacy reviews remain unresolved; weights stay local.

## Results

Both arms completed 1,500 steps (49.152M token positions) from the same EXP-0009 checkpoint with seed `20261028`. The Muon run used Muon for 2D transformer-block weights and AdamW for the remaining parameters. Checkpoint hashes are recorded in `runs/EXP-0033-evaluations/paired-development.json`.

### Decision

At this LR and 25M continuation budget, Muon provides a tiny next-token BPB improvement but does **not** establish a downstream-accuracy improvement. It is not a strong general-performance gain and is not enough to select a new 25M release checkpoint. This one-seed transfer result is exploratory; a larger learning-rate study or another seed pair would be needed before drawing a stronger optimizer conclusion.
