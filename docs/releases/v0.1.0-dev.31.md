# v0.1.0-dev.31

## Included

- Completes the CPU-side compiled controller prototype with a stored-program instruction set and arithmetic programs; documents its instruction and trace costs.
- Adds the preregistered EXP-0042 LFM3-VL-2B arithmetic comparison, relay and resumable 700-item runner. The documented 3-item smoke check is exploratory; the scored run has not been completed.
- Reports the EXP-0038/0039 world-model pilot at ceiling and records the EXP-0041 hybrid pilot results, including their limits.
- Fixes a CUDA-compatible reshape in local attention and corrects number parsing for thin-space grouped integers in the EXP-0042 scorer.

## Limitations

The compiled machine is still driven by Python calls and is not embedded in the language model's forward pass. EXP-0042 is preregistered but its full evaluation has not been run. The documented experiments use single seeds and exploratory settings; their results do not establish general performance gains. Automated tests were not run for this release.
