# v0.1.0-dev.37

SLM-Tavenel Story 935K now has a complete research model card and a verified private Hugging Face package at [athenista/slm-tavenel-story-935k](https://huggingface.co/athenista/slm-tavenel-story-935k). The user's condition concerning unresolved SimpleStories rights is preserved: this release does not make those weights publicly downloadable. Git contains the code, documentation, figures, source metadata and generated evaluation examples, not the weight files or real training stories.

Included:

- Standard Llama architecture and exact parameter breakdown; 256-token training-window limit stated separately from the configured 1,024-token positional limit.
- Training and validation logs, source/tokenizer/shard hashes, metadata-only source index, completion-group split audit, and the unchanged original dirty-run manifests.
- Five PNG/SVG figures: architecture, loss, same-text BPB/context comparison, per-layer observability and fixed-prompt head ablations.
- Exact exported-artifact dev BPB: 0.937012 on 3,185 SimpleStories stories, versus 1.670289 for the pinned tiny1m snapshot. This domain-specific single-seed comparison is not a neutral narrative-quality ranking.
- Thirty raw comparative continuations, blank review form and two fixed-prompt examples with token IDs and decoding settings. No blind human preference result is claimed.
- CPU timing, exact exported tensor mapping, rounded-weight logit checks and cached/uncached greedy checks. Thirteen targeted export/fluency tests passed; the generation CLI reproduced the archived sample.
- Source/configuration components from PR #1 plus the local corrected-split overlay are now available in the main source tree. PR #1 itself is not merged by this release, and the original run is not retrospectively described as clean.
