# v0.1.0-dev.32

## Included

- Improves the Hugging Face Transformers adapter with `DynamicCache` support, cache-aware attention masks and position handling, and configuration aliases for standard Transformers tooling.
- Adds tests for cached logits and generated-token parity. These tests are included but were not run for this release.
- Adds GPU energy tracking to new training runs, using NVML energy counters when available and power sampling as a fallback. Reports explicitly describe the GPU-board scope and do not estimate whole-system energy.
- Publishes a reproducibility archive for the five revised model cards, their benchmark and observability artifacts, the previous public-card snapshots, and the recorded Hugging Face revisions. The model weights did not change in this release.
- Adds scripts and recorded measurements for inference, KV-cache parity, quantization, safety screening, and EXP-0042 queue orchestration.

## Limitations

The KV-cache and energy tests were not run as part of this release. The cache measurements in the archive were taken against the recorded Hugging Face model-code revisions; the cache implementation in this source release is a subsequent code change and requires validation before it is copied to those model repositories. Safety screening is tooling only and has not been run. Quantization results are measurements on a small held-out sample; no quantized weights are released. EXP-0042 orchestration is provided, but the full scored experiment has not completed. Human data-rights and privacy reviews remain pending.
