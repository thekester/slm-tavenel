# v0.1.0-dev.38

[SLM-Tavenel Story 935K](https://huggingface.co/athenista/slm-tavenel-story-935k) is now a **public MIT-licensed research weight release**. The owner explicitly authorized public distribution after reviewing the prepared private package and its documented upstream uncertainty. The artifact hash and exact authorization are recorded in `docs/model-cards/slm-tavenel-story-935k/publication-decision.json`.

The package contains the standard Llama weights and tokenizer, complete model card, five architecture/evaluation/observability figures, raw examples, comparative continuations, training logs and source records. The weights are unchanged from the verified private preview: SHA-256 `8804d57668ac492454d9835841ff2a57f7867dbcbb36df4452ffedfa8813c9a8`.

The publication decision is limited to that weight file. It does not change the SimpleStories source from `candidate`, sign a human privacy review, establish the producer's historical generator-service terms or certify OSAID conformity. These reserves remain visible on the public model card.

The previous preview verified 13 targeted tests, native/export tensor mapping, rounded-weight logits, cache equivalence, same-source dev BPB, all package hashes and standard Llama inference after Hub download. This follow-up updates visibility and documentation; it does not introduce a new training run or a new scientific-performance claim. Anonymous public access and artifact hashes are checked after publication.
