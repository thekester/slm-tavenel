# v0.1.0-dev.30

## Included

- Adds a pure PyTorch gated delta-rule scan and `DeltaRAM`, a byte-addressable memory prototype.
- Adds fixed lookup-table MLPs and a decimal calculator for addition and schoolbook multiplication, with trace records.
- Documents the Qwenputer-inspired design study and the proposed LFM3-VL integration route.
- Records the implementation boundary: calculator control flow still runs on the host; a compiled controller and model integration remain future work.

## Limitations

This is an exploratory CPU prototype. It is not an integrated or trained SLM-Tavenel model and does not establish language-model arithmetic performance. The Qwenputer results cited in the study are author-reported and have not been independently reproduced here. Automated tests were not run for this release.
