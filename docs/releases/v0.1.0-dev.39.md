# v0.1.0-dev.39

The Story 935K same-domain advantage reverses on TinyStories. Both frozen public models were scored on all 21,990 official validation stories with the same byte-likelihood evaluator and 256-token chunk policy:

| Corpus | SLM-Tavenel Story 935K BPB | TinyStories tiny1m BPB |
|---|---:|---:|
| SimpleStories local dev | 0.937012 | 1.670079 |
| TinyStories official validation | 1.543090 | 1.045244 |

Lower is better. On TinyStories, Story minus tiny is +0.497847 BPB, paired document-bootstrap 95% interval [+0.491981, +0.503727]. This describes fixed checkpoints, not training-seed uncertainty or human coherence. The TinyStories validation text was used only for evaluation and is not redistributed.

The 1.670079 SimpleStories reference line uses the same explicit slow tokenizer as the new evaluation; the old automatic fast-tokenizer value 1.670289 is preserved with a nine-document / 44-token reconciliation. This is a loading correction, not a training improvement.

Also completed: corrective source/configuration files and a leakage regression test were committed and pushed to PR #1, head `4a06bbc`. The PR remains open; this release does not merge it. Fifteen tests passed on that branch and twenty targeted tests passed in main.

A loopback-only human-review form and analysis tool are available for the 15 existing anonymous pairs. Human ratings are still pending. No assistant-generated score, empty form or machine response is counted as completed human evidence. Private review keys, pseudonyms and notes stay local.

The model card is updated with the cross-source graph, exact inputs, compressed likelihood evidence and limits. Weights and the original MIT publication decision are unchanged.
