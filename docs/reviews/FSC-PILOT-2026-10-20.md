# French-Science-Commons candidate corpus: 2026-10-20

**Status:** prepared as an exploratory, token-balanced candidate; not independently rights-cleared
and not approved for public weight release. Exploratory training is recorded in
[EXP-0009](../../experiments/EXP-0009-fsc-scaling-and-references.md).

## Source and selection

The preparation uses only the `french_open_science` folder from PleIAs
[French-Science-Commons](https://huggingface.co/datasets/PleIAs/French-Science-Commons), pinned at
revision `bfa114c09d7c28dcd0a8a47fe445c64b4a3c6156`. It downloads the 48 parquet shards in that
folder. It excludes the separate `hal_open_access` folder, which the dataset card says contains
some copyrighted documents under additional publisher conditions.

The selector keeps only English and French page records with a nonempty source label, article ID,
page number, empty `terms`, and one of these exact per-record license values:

| Dataset value | Registry value | Treatment |
|---|---|---|
| `cc0` | `CC0-1.0` | Keep; no attribution condition under the license, while provenance remains recorded |
| `cc-by/4.0` | `CC-BY-4.0` | Keep; retain attribution metadata |
| `etalab-2.0` | `Licence-Ouverte-2.0` | Keep; retain source and update-date attribution |

The selector drops generic `cc-by` without a version, all `cc-by-sa` rows, `pdm`, other languages,
nonempty additional terms, and rows missing required provenance. Pages are grouped into articles.
Article IDs with inconsistent language, license, title/author/DOI/date/discipline, source (apart
from source-label case), or pages split across shards are excluded. A repeated page is deduplicated
only when its text is identical; conflicting text for the same article/page excludes the article.
Page-number gaps are retained and recorded because the upstream OCR may omit a page; the data is
not represented as complete OCR.

## Language balance

The complete 48-shard audit scanned **4,857,354 page rows** across **268,970 article IDs**. The
metadata audit excluded **4,234 IDs** for missing or genuinely inconsistent source labels. Other
per-record license values are either retained by the exact allow-list above or dropped by the
selector.

The completed audit loads title, author, publication date, DOI and discipline as well as page-level
language, license, source, terms and page fields. The corrected full audit again scanned 4,857,354
rows and excluded the same 4,234 article IDs as the earlier audit; it found no additional article
metadata conflicts. The excluded-ID sets match exactly. Its local record is
`data/raw/french-science-commons-pilot/document-metadata-audit-v2.json`.

After license filtering and article aggregation, the deterministic sampler selected documents by
SHA-256 order within each language/license group and matched English to French by whitespace-word
count. Before quality filtering, its targets were:

| License group | English words | French words |
|---|---:|---:|
| CC BY 4.0 | 174,241,594 | 174,241,594 |
| CC0 | 34,375,807 | 34,375,790 |
| Licence Ouverte 2.0 | 4,077,352 | 4,077,190 |
| **Total** | **212,694,753** | **212,694,574** |

These are pre-quality-filtering whitespace-word targets. After quality filtering and deduplication,
the pipeline retained **31,417 of 43,011 documents** (1,945,190,126 text characters). It removed
10,502 exact duplicates, 48 MinHash near-duplicates, and 1,044 documents via length/quality filters.
No document matched the four benchmark files under the configured exact 13-gram check. Pattern-based
PII filters redacted 64,641 emails, 5,108 phone numbers, 165 IP addresses and 7 IBANs; these are
redaction occurrences, not a count of documents or people.

After the initial tokenizer pass showed different English and French token fertility, the final
sample was rebalanced by **frozen-tokenizer tokens**, within each license class and separately in
train and validation. Whole documents remain intact. The tokenizer was trained only on the
document-level train split; validation documents were excluded. Final encoded totals are:

| Split | English documents | French documents | English tokens | French tokens | Absolute difference |
|---|---:|---:|---:|---:|---:|
| Train | 12,667 | 13,233 | 272,093,822 | 272,100,366 | 6,544 (0.0024%) |
| Validation | 685 | 678 | 13,832,444 | 13,842,423 | 9,979 (0.0721%) |

The final token balance, tokenizer and shard manifests are recorded under the ignored local `data/`
tree, including `data/processed/fsc-pilot-v1-token-balanced/final_token_balance_manifest.json`.
Every planned model arm must use these same frozen documents, tokenizer, train/validation split and
token budget; any deliberate change requires a new corpus version and manifest.

## Processing and limits

The prepared pipeline applies Unicode normalization, length and Gopher-style quality filters,
pattern-based PII redaction, full-text exact deduplication, 13-gram benchmark decontamination, and
MinHash deduplication using the first 512 whitespace words with 32 permutations. A generic web-text
repetition filter was evaluated and removed: sample false positives were valid academic content,
including repeated table markup, thesis headers, and references. The shortened MinHash check is a
compute compromise: it can miss near-duplicates that diverge in the opening 512 words or repeat only
later in an article. Exact-hash dedup still examines full text. Benchmark filtering is exact lexical
overlap only; it cannot rule out paraphrase, translation or semantic exposure.

The first-party preparation manifests and file hashes are under the ignored local `data/` tree:

- `data/raw/french-science-commons-pilot/download_manifest.json`
- `data/raw/french-science-commons-pilot/document-metadata-audit.json`
- `data/raw/french-science-commons-pilot/selected/selection_manifest.json` and `selected-remainder/selection_manifest.json`
- `data/raw/french-science-commons-pilot/documents/aggregation_manifest.json`
- `data/raw/french-science-commons-pilot/balanced/balance_manifest.json`
- `data/processed/fsc-pilot-v1-balanced/balance_manifest.json`
- `data/processed/fsc-pilot-v1-balanced/splits/split_manifest.json`
- `data/processed/fsc-pilot-v1/manifest.json`
- `data/tokenizer/fsc-pilot-v1-train-only/manifest.json`
- `data/processed/fsc-pilot-v1-token-balanced/final_token_balance_manifest.json`

The source registry deliberately keeps all six language/license source entries `candidate`. The
dataset card and per-record license fields provide traceability, but they are not an independent
verification of every publisher's rights claim. Before marking sources approved, check a sample and
then the full included record set against the originating publisher/repository terms, design an
attribution plan for CC BY and Licence Ouverte, and complete a privacy review. Pattern-based PII
redaction does not detect names or sensitive facts in scientific text. Until then, any training run
must be labelled exploratory, and weights are not cleared for public release.

## Reproduction

From the repository root on Windows PowerShell:

```powershell
python scripts/fetch_french_science_commons.py --count 48
python scripts/audit_french_science_documents.py `
  --input-dir data/raw/french-science-commons-pilot/shards/french_open_science `
  --output data/raw/french-science-commons-pilot/document-metadata-audit.json
$parquetFiles = Get-ChildItem -Recurse data/raw/french-science-commons-pilot/shards -Filter *.parquet
$argsList = @('scripts/select_french_science_commons.py','--output-dir','data/raw/french-science-commons-pilot/selected-all')
foreach ($file in $parquetFiles) { $argsList += @('--input',$file.FullName) }
python @argsList
python scripts/aggregate_french_science_pages.py `
  --input-dir data/raw/french-science-commons-pilot/selected-all `
  --output-dir data/raw/french-science-commons-pilot/documents `
  --exclude-audit data/raw/french-science-commons-pilot/document-metadata-audit.json
python scripts/balance_french_science_corpus.py `
  --input-dir data/raw/french-science-commons-pilot/documents `
  --output-dir data/raw/french-science-commons-pilot/balanced
python -m slm data run configs/data/pipeline-fsc-pilot.yaml --allow-unapproved
python scripts/balance_processed_fsc.py `
  --input data/processed/fsc-pilot-v1/documents.jsonl `
  --output-dir data/processed/fsc-pilot-v1-balanced
python scripts/materialize_fsc_balanced.py `
  --input-dir data/processed/fsc-pilot-v1-balanced `
  --output-dir data/processed/fsc-pilot-v1-balanced/documents
python scripts/split_fsc_documents.py `
  --inputs data/processed/fsc-pilot-v1-balanced/documents/en.jsonl data/processed/fsc-pilot-v1-balanced/documents/fr.jsonl `
  --output-dir data/processed/fsc-pilot-v1-balanced/splits --val-fraction 0.05
python -m slm tokenizer train `
  --inputs data/processed/fsc-pilot-v1-balanced/splits/en-train.jsonl data/processed/fsc-pilot-v1-balanced/splits/fr-train.jsonl `
  --out data/tokenizer/fsc-pilot-v1-train-only --vocab-size 8192 --seed 20261020
python scripts/balance_fsc_by_tokens.py `
  --inputs data/processed/fsc-pilot-v1-balanced/documents/en.jsonl data/processed/fsc-pilot-v1-balanced/documents/fr.jsonl `
  --tokenizer data/tokenizer/fsc-pilot-v1-train-only `
  --output-dir data/processed/fsc-pilot-v1-token-balanced --val-fraction 0.05
foreach ($language in @("en", "fr")) {
  foreach ($split in @("train", "val")) {
    python -m slm data encode --tokenizer data/tokenizer/fsc-pilot-v1-train-only `
      --inputs "data/processed/fsc-pilot-v1-token-balanced/$language-$split.jsonl" `
      --out "data/tokens/fsc-pilot-v1-final/$language/$split" --val-fraction 0.0
    if ($LASTEXITCODE -ne 0) { throw "Encoding failed for $language/$split" }
  }
}
python scripts/write_fsc_final_manifest.py `
  --balanced-dir data/processed/fsc-pilot-v1-token-balanced `
  --tokenizer data/tokenizer/fsc-pilot-v1-train-only `
  --tokens-dir data/tokens/fsc-pilot-v1-final --val-fraction 0.05
```

The four token-balanced JSONL files are encoded separately with the frozen tokenizer. Validation
files are already held out by document ID; a zero encode-time fraction keeps every document in its
named output directory. The final manifest writer checks document and tokenizer hashes, rejects
empty or re-split encoded inputs, and joins their counts. It does not re-audit tokenizer-training
separation or rehash the token binaries.

The repository pipeline above is `configs/data/pipeline-fsc-pilot.yaml`. It currently needs
`--allow-unapproved`, which is recorded in its manifest and is appropriate only for exploratory
work while these sources remain candidates.
