# EXP-0046 audit, 11 November 2026

EXP-0046 provides an exploratory comparison of representation geometry. It does not yet provide a robust reproduction of the paper or evidence that a 124M language model generally outperforms larger models. The useful claim is restricted to the held-out neighbour-overlap metric, these checkpoints, this dataset and DINOv2.

N's 0.123720 rounds to **0.1237**, not the original JSON's 0.1238. An unbatched first-block check also gives 0.123720; six checked vectors are bitwise equal to the full legacy extractor. Therefore the tiny discrepancy cannot be attributed only to batching. The original per-image vectors/scores and immutable runtime manifest were not saved, so its precise cause cannot be established. We report the -0.00008 difference from the original rounded value rather than claiming exact reproduction. A post-hoc numerical tolerance of 0.0002 is used only to flag a materially inconsistent reproduction; it does not change the scientific +0.02 threshold. J and the primary difference still match their reported four-decimal values.

In 499 post-hoc shuffled-correspondence draws, both models' null overlap averages about 0.00401, matching chance. The observed J-minus-N is above every shuffled difference (one-sided Monte Carlo p = 0.002, the finite-draw floor). This diagnostic is conditional on the current checkpoints and graphs; it is not a substitute for new seeds or new datasets.

## Verified inputs and implementation

- COCO annotation SHA-256 values and the tokenizer hash match the preparation manifest. Every one of the 591,753 stored caption token sequences is reconstructed from the original human annotation and tokenizer, including padding and truncation. Train groups cover 118,287 image IDs; evaluation covers 5,000 different IDs.
- Both objectives use the same deterministic per-step caption-pair sampler, 9,000 updates and 256 sampled images per update. Pair indices are distinct; identical caption text can still occur. There are 202 train images with duplicated normalized caption text.
- J uses a predictor-free VICReg-style loss on mean-pooled, final-normalized states and a 147,456-parameter auxiliary linear projection. N uses next-token cross-entropy. Tests check that the custom chunked NTP loss has the same value and gradients as the full-logit loss and ignores padding.
- Both evaluated backbones have 124,038,144 unique parameters. The auxiliary J projection is dropped at evaluation. Equal updates/caption exposure do not imply equal FLOPs, training parameters, energy or runtime.
- The layer-selection and primary-scoring images are disjoint, 2,500 each. The original JSON reports J 0.1792, N 0.1238 and J minus N +0.0554 with fixed-graph paired-bootstrap interval [0.0493, 0.0616].
- Six fixed DINO cache anchors, spanning the row order, are re-embedded with the pinned model and processor. Maximum absolute difference is 0.00000775. All 5,000 current image files are hashed. This is not a full independent recomputation of the original image cache.

## Corrections to the interpretation

| Point | Audit finding | Consequence |
|---|---|---|
| Caption overlap | 440/5,000 evaluation captions match training text after case/whitespace normalization; only 4,958 normalized captions are unique within evaluation | Image-ID separation is verified, text independence is incomplete. Report a post-hoc sensitivity without matching captions |
| Registration chronology | First protocol/evaluator commit `34a9277` is 10 November 16:45:58 Paris; J training ended 15:25; alignment evaluation began 21:25 | Specification before alignment results is evidenced. Registration before any training is not established |
| Random control and retrieval | Original R@1: J 0.0404, random 0.0462. Original R@5: J 0.1544, random 0.1488 | “Slightly above random” is false for R@1 and was corrected |
| Bootstrap scope | Resamples precomputed node scores from one shared neighbour graph | Does not establish uncertainty over new graphs/scenes or training seeds |
| Energy | N final resumed-trajectory counter 295.089 Wh omits discarded partial segments | Their logged increments total 11.078 Wh; known logged N energy is at least 306.167 Wh, plus unlogged work |
| Training supervision | J sees no image pixels but uses caption-to-image group membership | Do not describe it as learning without any scene-group supervision |
| Public models | They were not trained by us in the matched COCO conditions; upstream caption/photo exposure is unknown | Reference ranking mixes objectives, training data, budgets and architecture |
| Paper reproduction | Our causal decoder/VICReg proxy differs from the paper's BERT/LeJEPA/SIGReg recipe and preprocessing | The paper's scores, especially its 72B comparisons, cannot be compared numerically to this experiment |

The [paper](https://arxiv.org/abs/2610.39302) links [released source code](https://github.com/galilai-group/prh-proof). The repository's earlier “no code link found” note has been corrected. A related positive local finding is not a theorem verification or a full replication.

The original rotation retrieval fits PCA and rotation on separate fit folds, but additionally recenters each test cohort. This is transductive preprocessing, not leakage of paired test labels into the rotation. A fit-only-centering sensitivity is reported separately. Retrieval layer choice still uses the primary metric, so these secondary scores remain descriptive.

The original native extractor observes block outputs before the final RMS normalization; public-model `hidden_states` can include final-normalized last-layer outputs. Tokenizer special tokens and truncation also differ. These heterogeneous choices do not change the J/N backbone-controlled comparison, but merit harmonized sensitivity before claiming a universal public-model ranking. The linear CKA here is biased linear CKA, not the paper's unbiased HSIC-based CKA.

## Provenance and repairs

Original result files, current-at-audit source files and the pre-existing uncommitted experiment write-up are preserved under `runs/EXP-0046-audit-2026-11-11/original-inputs`. They are not rewritten as newly executed or pre-registered evidence. The old result file remains unchanged.

`scripts/audit_exp0046.py` verifies data, re-extracts J/N on CPU, reconstructs primary scores and the original bootstrap, and computes two explicitly post-hoc diagnostics: removal of training-caption matches and shuffled image/text correspondence. It preserves input-bound native feature caches and records checkpoint hashes, actual backbone/projection counts, environment and code hashes. Length-bucketed batches avoid padding and unused vocabulary logits; pooling and original row order are tested, with real anchors checked against legacy extraction. Read-only audit restarts and extraction-source snapshots are retained locally. Original training and evaluation are untouched. A postprocessing-only cache migration verifies extractor AST equivalence against its preserved source and retains the actual extraction-source hash.

`scripts/evaluate_text_image_alignment_audited.py` is the evaluator for future runs, with unchanged legacy primary definitions. It refuses existing result paths and unbound/stale image caches, binds cache rows/image bytes/encoder revision/software versions, and persists selected feature arrays, primary per-image scores and input manifests. The queue now uses it for future evaluations. The original evaluator is retained to reproduce historical numbers. Cache checks and a complete synthetic evaluator run are covered by regression tests.

For a fresh evidence-producing J/N evaluation, use a new cache/output path; the original DINO cache intentionally lacks a retroactive full-extraction manifest:

```powershell
$env:PYTHONPATH = 'src'
python scripts/evaluate_text_image_alignment_audited.py --native J=runs/EXP-0046-124m-jepa/checkpoints/step_00009000.pt --native N=runs/EXP-0046-124m-ntp/checkpoints/step_00009000.pt --compare N=J --cache runs/EXP-0046-evaluations/dinov2-val2017-bound-v1.npy --out runs/EXP-0046-evaluations/text-image-alignment-audited.json
```

The custom trainer's generic saved `TrainConfig` does not fully describe its CLI loop: default `micro_batch_size` and `seq_len` fields are not the actual 256-image batch and 48-token preparation cap, and complete CLI mode/dim metadata were not saved. Source/defaults can reconstruct the intended recipe, but a complete original runtime manifest is absent. Late hashes and snapshots improve auditability without retroactively proving original execution state.

Future custom training runs now capture actual CLI arguments, configuration/data/source fingerprints, backbone/auxiliary counts and checkpoint resume lineage, and reject changed configurations or data on resume. A first manifest captured only on a legacy resume is explicitly labelled retrospective. New checkpoint metadata carries this custom-loop fingerprint. This adds provenance fields without changing either objective.

## Remaining before a robust claim

1. Replicate paired J/N trainings with several seeds, then quantify training-seed uncertainty.
2. Add a matched joint-embedding control with shuffled positive caption groups, to isolate the role of good-view relations from objective/projection effects.
3. Check another vision encoder and multiple captions per image. Verify perceptual train/val image duplicates and, where possible, upstream reference exposure.
4. Evaluate scene/graph uncertainty instead of treating fixed-graph node scores as independent observations. Treat additional reference comparisons as exploratory or adjust a declared family of confirmatory tests.
5. Independently regenerate all public-reference features with complete manifests and harmonized pooling/normalization checks. This audit reruns J/N; public-model values are otherwise checked against the original JSON/log, not independently rerun.
6. Before a new training, save the actual CLI arguments, data/model/tokenizer hashes, auxiliary parameter count, code snapshot, initial backbone hash, resume lineage and an energy ledger including discarded segments.

No new training, 72B evaluation or hosted data upload is part of this audit. No evidence here establishes visual understanding, language-generation quality or superiority on general benchmarks.
